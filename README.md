# Электромонтаж дома PRO

Браузерное приложение без backend для предварительного проектирования электромонтажа частного дома/квартиры.

## Запуск
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
npm run preview
```

## Возможности
- SVG-план с комнатами и электрическими точками, drag & drop
- каталог оборудования и пользовательские параметры точек
- группы, нагрузка, коэффициент спроса, подбор кабеля и автомата
- падение напряжения, проверки и предупреждения
- распределительный щит и оценка DIN-модулей
- BOM с ценами в ₸
- localStorage + автосохранение
- JSON импорт/экспорт, XLSX и PDF
- адаптивный интерфейс

Все расчёты предварительные и не заменяют проектирование квалифицированным специалистом по действующим нормам.
